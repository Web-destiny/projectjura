# План и решения

1. Модульный Vue/Vite skeleton, токены и UI.
2. Независимый domain; IndexedDB с одним черновиком и явными шаблонами.
3. OOXML: XML DOM, индекс символов внутри абзаца, адреса part/paragraph/start/end; замены справа налево с сохранением run начала поля.
4. Worker provider: анализ, генерация, таблицы, архивы, перенос шаблонов. Отмена через terminate с перезапуском worker.
5. Единая таблица данных, визуальные поля, проверка и генерация.
6. Два режима массового изменения; библиотека шаблонов и .dzhura.
7. Гайд, тесты реальных OOXML/XLSX/CSV, E2E, benchmark, production.

ExcelJS + PapaParse выбраны как зрелые библиотеки XLSX и CSV. Никаких запросов с документами, внешних шрифтов или аналитики. Preview изолирован от интерфейса в sandbox iframe. Разметка preview не участвует в генерации. Визуальные поля выделяются в точном текстовом представлении OOXML, рядом доступен постраничный preview: это исключает угадывание адреса по одинаковому тексту.
